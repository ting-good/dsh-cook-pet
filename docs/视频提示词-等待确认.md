# 等待确认 · 完整视频生成提示词（托腮思考）

> 用途：agent **等待用户确认 / 等待输入** 时的持续状态动作
> 规格：**16:9 / 1280×720**，**5 秒**，**循环友好**（首尾帧=同一托腮姿势，可无限 loop）
> 与其它动作不同：本段的**首尾帧不是持铲站姿，而是托腮姿势**——因为等待是持续状态，需要能被长时间循环播放；进入/退出该状态由客户端的交叉淡化承担。

## 生成命令

```powershell
$node  = 'C:\Users\admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe'
$video = 'D:\Deepseek\DSwork\agnes-video\agnes-video.mjs'

& $node $video '<下面的完整提示词>' --seconds 5 --ratio 16:9 --name 等待_托腮
```

> 托腮涉及手部，**建议一次生成 3~4 条挑一条**（成本很低）。
> 若手部始终崩坏，把提示词里的托腮句替换成文末的「Plan B 降险变体」。

## 完整提示词（主版本）

```
【角色锚定句】
Q版二头身日系动画风格小女孩：深栗棕色（#5C3B2A）蓬松微乱的齐刘海短发，画面右侧扎一个低侧马尾、系大红色（#E03A3A）蝴蝶结；头戴白色蓬松高厨师帽，帽带正面有淡粉色兔耳形徽记；刘海右侧别一枚白色小兔子发夹（带淡粉腮红）；琥珀棕色大眼睛（#8B5A2B 渐变至 #C98B4B，带白色高光），眼下有淡粉腮红；穿白色立领厨师上衣（前襟两颗红色圆扣），外罩珊瑚红（#E8503F）围裙（双肩带、两个金属圆扣、右侧腰部系蝴蝶结、下摆带白色蕾丝边、正面有白色兔子口袋图案）；白色蓬松短裤、白色中筒袜、深棕色光面短靴；右手持一把黑色镂空锅铲（四孔煎铲）。表情开朗，常带笑。

【画风锚定句】
日系Q版动画风，赛璐璐平涂上色加柔和渐变阴影，干净利落的深棕色描边（2~4px），色彩明亮饱和、不脏；无写实皮肤纹理、无厚涂笔触、无噪点、无景深虚化、无3D渲染感。

【视频通用约束】
画幅 16:9，正对镜头的平视固定机位，无透视畸变。人物双脚落点恒定为屏幕正中央，全程不允许产生 X 轴或 Y 轴平移位移；不允许后退、走位、偏左或偏右。背景为纯净单一的绿幕色（#00FF00），无渐变、无地面线、无投影、无杂物。禁止任何文字、水印、签名、logo、对话框；不出现第二个人物；不改变发型发色、瞳色与服装配色。
第 0 秒与第 5 秒必须是**完全相同的托腮姿势**：身体正面朝向镜头、头微微歪向画面右侧约 10 度、左手手背轻抵下巴右侧、右手持锅铲自然垂在身体右侧、双脚并拢站立、眼睛看向镜头略偏上方、嘴角轻抿带一点笑意。（首尾帧一致，可无缝循环。）

【动作概述】
小厨娘站在原地等你拿主意。她把左手手背轻轻抵在下巴侧边，脑袋微微歪着，眼睛看向镜头斜上方，像在盘算"今天做什么菜好呢"；右手握着锅铲松松地垂在身侧，铲子随呼吸极轻微地晃。她安静地保持着这个姿势，中途轻轻点两下头、慢慢眨一次眼，肩膀随呼吸微微起伏——耐心、困惑又可爱，完全没有催促的意思。

【按秒分割画面】
0~1.2 秒：保持托腮姿势。身体随呼吸做极轻微的上下起伏（幅度不超过画幅高 1.5%）；右手锅铲随呼吸轻轻晃一下；双眼看向镜头略偏上方，嘴角轻抿。
1.2~2.4 秒：眼睛缓慢地眨一次（眼睑闭合约 0.25 秒再睁开）；头保持歪约 10 度不变；左手手背仍轻抵下巴，不移动位置。
2.4~3.6 秒：脑袋轻轻地点两下（幅度很小，约 3 度，像"唔……"地思考），眉毛微微上扬；脸颊红晕略加深。
3.6~5 秒：身体回到稳定的托腮姿态，右手锅铲再轻晃一下，视线仍看向镜头略偏上方。第 5 秒与第 0 秒完全一致。

【动作结束后状态】
与首帧完全一致的托腮姿势（本章首尾帧均为托腮姿，而非持铲站姿）：头歪约 10 度、左手手背抵下巴右侧、右手持锅铲垂在身侧、双脚并拢、视线朝向镜头略偏上方。可被客户端无缝循环；退出时用交叉淡化切回待机。
```

## 关键降险写法（为什么这样写）

| 风险 | 提示词里的对策 |
| --- | --- |
| 手指画崩、多指 | 用**手背**抵下巴、**手指半握不张开**，不给模型画五根手指的机会 |
| 手挡住嘴和眼睛 | 限定手在**下巴右侧的侧缘**，明确"不遮挡嘴部与眼睛" |
| 眼睛翻白或走神崩坏 | 视线只"略微偏上"，**不翻眼白、不离开画幅** |
| 头转导致第二张脸 | 头只**歪 10 度**，全程**不左右旋转**，脸始终正面朝镜头 |
| 人物横移 | 写死"双脚落点恒为屏幕水平正中、无 X/Y 平移" |
| 循环时跳帧 | 首尾帧**都是同一托腮姿势**（本动作不闭环回持铲站姿） |

## Plan B 降险变体（手部仍崩时替换）

把【动作概述】与按秒分割里的托腮句替换为：

```
小厨娘把锅铲竖直举起、铲柄顶端抵在下巴下方，双手扶着铲柄，下巴轻轻搁在铲柄上，脑袋歪着看向镜头斜上方，像撑着铲子发呆。
```

理由：**锅铲是硬质道具**，模型渲染硬物的稳定性远高于渲染手指；用铲柄当支点托住下巴，既保留"托腮发呆"的可爱语义，又完全避开了手部细节。

## 语义与触发时机建议

- 触发：`approval/request`（请求权限确认）、等待用户输入、或长任务中 `agent/status` 停在等待态
- 若客户端只想做"一次性提示"，也可以把本段作为**插播**：托腮 3 秒后淡回待机，表示"我在等你"
- 与 `wink` / `spin` 不冲突：那两个是**点击响应**，这个是**状态动作**
