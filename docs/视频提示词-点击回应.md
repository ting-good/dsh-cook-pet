# 点击回应 · 完整视频生成提示词（wink / 转圈）

> 对应素材源：`wink.mp4`、`spin.mp4`（本仓库不包含素材源，见 README「想换成自己的角色」）
> 规格：**16:9 / 1280×720**，`wink` **4 秒**、`spin` **5 秒**（与现有素材一致）
> 桌面窗行为：点击时从 `wink` / `spin` 中**随机挑一个**，**只播一次**（`loop = false`），播完自动切回当前状态；有 6000ms 兜底计时。
> 因此两段视频的**首帧与末帧都必须是标准持铲站姿**——否则播完切回待机时会跳帧。

## 生成命令

```powershell
$node = 'C:\Users\admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe'
$video = 'D:\Deepseek\DSwork\agnes-video\agnes-video.mjs'

# wink：4 秒
& $node $video '<wink 完整提示词>' --seconds 4 --ratio 16:9 --name 点击_wink

# 转圈：5 秒
& $node $video '<转圈 完整提示词>' --seconds 5 --ratio 16:9 --name 点击_转圈
```

> `--seconds` 取值范围是 4–12，4 和 5 都在范围内；`--ratio 16:9` 输出 1280×720。
> 若要首尾帧严格锁定，可额外传 `--first-frame`/`--last-frame`（都指向同一张待机基准立绘）。

## 三条容易翻车的约束（务必保留在提示词里）

1. **首尾帧闭环**——点击响应是"插播"动作，播完要切回 idle / cook / serve。首末帧若不是同一站姿，切换时会明显跳一下。
2. **禁止位移**——模型很爱在"转圈/跳跃"时顺手把人物往左右挪。必须写死"双脚落点恒在画面水平正中"，否则素材叠不到同一位置。
3. **跳跃/举铲不得顶到画幅边缘**——最高点（铲尖、厨师帽）距画幅顶边至少留 10%，否则会被裁掉。

## 与桌面窗参数的对应关系

| 项 | 值 | 来源 |
| --- | --- | --- |
| 随机集合 | `['wink', 'spin']` | `runtime/electron-helper/renderer.js` `CLICK_ACTIONS` |
| 播放方式 | `once`（不 loop） | `renderer.js` 的 `playClickReply()` |
| 兜底时长 | 6000ms | `renderer.js` `CLICK_FALLBACK_MS` |
| 建议素材时长 | wink ≤ 4s、spin ≤ 5s | 须小于兜底 6000ms，否则会被提前切断 |

> 点击回应**不显示任何文字**：只播动作。早期版本会弹一句气泡（`嘿嘿，被你发现啦～` /
> `转个圈给你看！`），后来按要求全部去掉了 —— 表情本身已经足够，多一行字反而打断视线。
